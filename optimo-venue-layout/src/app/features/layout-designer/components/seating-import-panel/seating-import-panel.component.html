Bulk seat fill (CSV)

Upload a CSV with one row per block — block_code, rows, and columns (capacity optional). Chair size, gaps, and edge_margin_m are read as metres. Optional curve_deg, center_row_aisle_widths_m, and center_column_aisle_widths_m apply when seats are created. Incomplete row_seats (e.g. 1-2:8|3-4:) fills from columns. The VIEW POINT is aimed at the pitch automatically and row A of every block faces it. In Excel use Save As → CSV.
